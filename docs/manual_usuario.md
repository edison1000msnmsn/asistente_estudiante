# Manual de usuario

## Inicio

Abre la aplicacion y revisa la presentacion inicial. Puedes tocar `Comenzar` o `Saltar`.

## Crear perfil

Ingresa un apodo, selecciona edad, avatar y nivel educativo. No se solicita nombre completo.

## Jugar

Desde el inicio elige Matematicas, Letras, Arte o Logica. Cada pantalla muestra una pregunta, elementos visuales y cuatro opciones.

## Estrellas y niveles

Las respuestas correctas entregan estrellas. Al completar actividades se avanza de nivel y se pueden desbloquear medallas.

## Progreso

La pantalla Progreso muestra estrellas, nivel, avance por modulo y medallas.

## Padres o docentes

Ingresa al panel adulto con PIN `1234`. Alli se revisan aciertos, errores, tiempo de uso y recomendaciones pedagogicas.

## Reiniciar avance

En Configuracion selecciona `Reiniciar progreso` y confirma la accion.

## Uso responsable

Se recomiendan sesiones de 10 a 15 minutos con acompanamiento adulto.
