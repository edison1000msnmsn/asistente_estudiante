Cambios de esta maqueta

Inicio mas academico y visual, menos texto, mejor jerarquia para estudiante y dashboard admin con metricas claras.

Para estudiante

  • Solo datos, estado, hora objetivo, cola y resultado.
  • Botones principales visibles y separados.
  • Solicitar cupos solo aparece cuando el alumno tiene 0 cupos.
  • Resultado con escenarios visuales: exito, preparado, agotado, sin cupos y cerrado.
  • El codigo acepta la letra en mayuscula o minuscula sin diferencia.

Para administrador

  • Dashboard con alumnos, tickets, timeouts y limite global.
  • Cola con texto claro: intentos usados, no cupos reales.
  • Diagnostico visual para decidir ajustes futuros.
